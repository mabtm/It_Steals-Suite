# Elite-Suite 7.24 Preview

These are captures of the actual production ImGui renderer with synthetic test data. They show interface behaviour and layout, not a running game or proof of the Unity export fix.

- 01-speedrun-hud.png: Random Seed / Set-Seed category, validity badge and matching per-crystal deltas.
- 02-replay-library.png: Native recording list, preserved mode/category/status filters and sorting; detailed table remains available.
- 03-run-setup.png: Mode selection with draft-category personal bests; Practice bests are separate and unranked.
- 04-run-check.png: Recorded category kept visible in the end-of-run verification.

Set-Seed clip splits default to on when a compatible reference exists. Their position, width and opacity can be changed in Clip Studio > Overlays; source-time animation and an immutable reference are retained for export.

Development channel only. Stable releases and the normal updater remain unchanged.
