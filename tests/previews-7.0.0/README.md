# Gerenderte Oberfläche 7.0.0 / mab

Tatsächliche ImGui-Ausgabe aus ui_tests.cpp, mit dem erfassten Alpha-Fontatlas gerendert. Synthetische Run-/Karten-/Diagnosedaten; Host-Schrift DejaVu Sans. Keine Windows-/Unity-Liveaufnahme. Hauptansichten bei 1920 × 1080 / 100 % DPI; Appearance ist ein zusätzlicher kleinerer Testviewport.

Intro, Compact HUD, gültiger/ungültiger Run-Abschluss, F8-Abfrage, große Replay-Karte mit Monster/Flash, pulsierender Spawnfilter, Seed-Vorschau mit ausgeschalteter Optimalroute, ausgeführter Diagnose-Scan und Modusmeldung. Die genaue Anordnung von Hinweisen wird im Spiel aus den gerade sichtbaren HUD-Flächen berechnet.
