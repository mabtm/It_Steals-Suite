# Native GUI-Vorschau 7.1.0 / mab

Echte ImGui-Zeichenausgabe mit synthetischen Testdaten; keine Windows-/Unity-Liveaufnahme. gallery.html ist selbstständig und bietet vergrößerbare Einzelbilder. interface-tour.gif zeigt die vorhandenen Effekte ohne Ton. Der eigene PB-Ton ist im Trainer hörbar. Die HUD-Kachel kombiniert voneinander unabhängige Profilvorschauen; die Minimap bleibt im Clean-Speedrun gesperrt.

Font-Rasterung im Host: DejaVu Sans als Testersatz. Windows verwendet die im Trainer gewählte verfügbare Schrift. Bilder werden ausschließlich aus tests/ui_tests.cpp und design_ui_cases.inl erzeugt; keine erfundene Spielaufnahme.
